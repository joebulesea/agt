# 未發布：分組收尾

類型：新增（MINOR）。發布時把下面這一行併入 `CHANGELOG.md` 的「未發布 → 新增」，並刪除這個檔案。

## CHANGELOG 條目

- 分組收尾：Agent 在 `.agt/groups/<組名>/` 放 `FILES`、`COMMIT_MSG`、`PR_BODY.md`，收尾 pr / merge 時每組各自一個 commit（pr 各自一個 PR），未認領的變更自成 `rest` 組。說明見 `docs/Agent-分組收尾說明.md`

## 細節

- **pr**：每組建立獨立 branch `<任務 branch>-<組名>`（內容 = merge-base + 該組檔案，一個 commit），各自 push 並開 PR；已有 PR 時只追加 commit、更新說明，不 force push。
- **merge**：每組一個 commit 依序合進 base（merge＝每組一個 merge commit、squash＝每組一個 commit、rebase＝逐組 cherry-pick）；任一組衝突即停下，已合進去的組保留。
- 收尾結果視窗顯示「分成 N 組：N 個 commit、N 個 PR」與各組標題、branch、PR 網址。
- 沒有 `.agt/groups/` 時行為不變。
- 使用說明與可貼進 Agent 提示的版本：`docs/Agent-分組收尾說明.md`；`config/default.toml` 的 `claude-docker`、`claude-sbx` 範例提示已加入分組說明。
